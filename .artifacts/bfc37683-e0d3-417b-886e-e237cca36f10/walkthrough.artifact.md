## الخطوات الحاسمة (يرجى التنفيذ بدقة)

> [!CAUTION]
> **خطوة الرفع (Git Push)**:
> يرجى تشغيل الأوامر التالية لرفع الكود "المقاوم للانهيار":
> ```bash
> git add .
> git commit -m "System: Fault tolerance and global error catching enabled"
> git push origin main --force
> ```

> [!IMPORTANT]
> **خطوة تنظيف المتصفح (Clear Cache)**:
> بعد اكتمال الرفع في فيرسل، يجب عليك القيام بالآتي في متصفحك:
> 1. افتح الموقع.
> 2. اضغط **F12** لفتح أدوات المطور.
> 3. اذهب لتبويب **Application**.
> 4. اختر **Storage** من القائمة اليسرى.
> 5. اضغط على زر **Clear site data**.
> هذا سيحذف النسخة القديمة جداً العالقة في جهازك والتي تطلب روابط ملغية.

بعد القيام بذلك، جرب الدخول للوحة التحكم. إذا ظهر خطأ، فإنه سيكون عبارة عن رسالة JSON تخبرنا بالمشكلة بالضبط، ولن تكون مجرد شاشة بيضاء أو خطأ 500 مبهم.
